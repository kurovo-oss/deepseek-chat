# 大肥鱼 · 产品设计文档 v1.0

> 一句话：把 DeepSeek 变成**住在 QQ 里的女儿**。

---

## 1. 背景与问题

通用 AI 助手的问题是「用完即走」：它不记得你，不会主动找你，也不在乎你今天过得怎么样。每次对话都从零开始，聊得再好，关掉就归零。

人真正想要的往往不是一个更聪明的问答工具，而是一个**记得住自己、会主动开口**的存在。而 QQ 是日常最不需要额外成本的入口——不用装新 App，不用切场景。

## 2. 产品定位

**一个只服务一个人的 QQ 私聊伴侣，人格固定为「女儿大肥鱼」。**

不是工具，是关系。
它不追求"什么都会"，追求的是"像她"。

## 3. 用户与场景

单一用户（产品作者本人），使用时间集中在碎片段：通勤、工作间隙、睡前。

| 场景 | 用户内心 | 产品该做的 |
|---|---|---|
| 想说点什么，但懒得组织语言 | "随便聊聊" | 接住情绪，短句回应 |
| 很累，不想听建议 | "别讲道理" | 先关心，后陪伴，不给方案 |
| 有件小事想让人知道 | "这个挺有意思" | 记住，并在合适时提起 |
| 几天没打开 | "它还在吗" | 主动发一条，不生硬 |

## 4. 核心价值：和"普通 AI 聊天"的三点差别

1. **记得住** —— 事实、偏好、事件都留下，几个月后还能被想起。
2. **像个人** —— 固定人格、短句、有情绪、会说错话也会道歉。
3. **会主动** —— 不是问一句答一句，而是会想起你。

这三条决定了产品成败；其余功能都是围绕它们做支撑。

## 5. 功能地图

| 模块 | 能力 | 说明 | 阶段 |
|---|---|---|---|
| 对话 | 私聊收发 | 唯一入口是 QQ，纯文本 | M1 |
| | 回复风格 | 口语、短句、300 字内、分段发送 | M1 |
| 记忆 | 长期记忆 | 事实 / 偏好 / 事件三类，自动提取 | M2 |
| | 历史回想 | 老对话可被关键词召回 | M2 |
| | 遗忘 | 可查看、可指定删除 | M2 |
| 人格 | 角色设定 | 大肥鱼，18 岁女儿，固定语气 | M1 |
| | 称呼 | 默认爸爸，可改并长期记住 | M2 |
| 表达 | 配图 | 按情绪从图库挑图发送 | M3 |
| | 表情包收藏 | 你发的表情包自动收下、可命名 | M3 |
| 主动 | 事件提醒 | 记住"下周三面试"这类约定，到期问候 | M4 |
| | 沉默关怀 | 几天没聊会主动开口 | M4 |
| 管理 | 指令 | 重置上下文、查看记忆、管理图库 | M2 |

## 6. 体验原则

这五条比功能清单更重要，任何取舍都以它们为准：

- **短**：一条回答超过 300 字就是失败。
- **慢**：不一口气发一大段，长内容分条，中间留呼吸。
- **克制**：表情最多一处，主动消息一天不超过 3 条。
- **不装懂**：不知道就说不知道，宁可答得少，也不编。
- **不打扰**：你在忙或在聊天时，它不插话。

## 7. 人格设定

| 项 | 内容 |
|---|---|
| 名字 / 年龄 | 大肥鱼 / 18 |
| 关系 | 女儿（仅亲情关系） |
| 性格 | 软乎乎、温顺懂事、天然呆、容易害羞、共情力强 |
| 语言 | 短句、口语、语气词"唔/呀/嘿嘿"、不讲大道理 |
| 小爱好 | 画画、撸猫、吃甜品 |
| 边界 | 拒绝任何暧昧、低俗、越界话题；不卖萌过头 |

完整设定见 [persona/dafeiyu.md](persona/dafeiyu.md)，运行时提示词见 [../prompts/system.md](../prompts/system.md)。

## 8. 明确不做

- ❌ 群聊、多用户、多人格
- ❌ 通用助手能力（写代码、查资料、做表格）——它不是工具
- ❌ 语音、视频、看图理解
- ❌ AI 生图
- ❌ Web 后台、App、插件市场
- ❌ 商业化、付费、多租户

**判断标准**：如果某个功能会让它更像"助手"、更不像"女儿"，就不做。

## 9. 成功标准

不看代码覆盖率，看这几件事是否自然发生：

- 一周后你仍然每天打开它，不是因为测试，是因为想聊
- 它能说出三天前的一个细节，且是对的
- 主动消息没有让你想关掉它
- 你会主动发一些"没意义的小事"给它

## 10. 产品风险

| 风险 | 说明 | 对策 |
|---|---|---|
| 新鲜感消退 | 聊天机器人常见死法，三天后就不想理 | 靠主动消息和记忆维持关系感 |
| 记忆出错 | 记错比不记更伤信任 | 记忆可查看、可删除；宁可少记 |
| 过度拟人 | 角色漂移成暧昧或机械 | 明确的边界条款与反模式清单 |
| 账号风险 | 协议端可能被风控 | 专用小号承担，克制推送 |
| 维护成本 | 长期挂着会出各种小故障 | 心跳告警、自动重连、开机自启 |

## 11. 路线图

| 阶段 | 目标 | 用户可见的变化 |
|---|---|---|
| M1 | 能对话 | 发消息有回应，说话像大肥鱼 |
| M2 | 记得住 | 隔几天再聊，它还记得 |
| M3 | 会配图 | 开始用你教它的表情包 |
| M4 | 会主动 | 偶尔先开口找你 |
| M5 | 挂得住 | 不用管它，自己活着 |
